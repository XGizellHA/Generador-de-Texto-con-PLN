# Generador-de-Texto-con-PLN
Este proyecto fue desarrollado para la materia de Procesamiento de Lenguaje Natural.  El objetivo fue crear un modelo capaz de generar cuentos y canciones de manera automática utilizando técnicas de Deep Learning y Procesamiento de Lenguaje Natural. 


### Metodología
1. Recolección y preparación del corpus de texto.
2. Limpieza y preprocesamiento de datos.
3. Tokenización mediante Byte Pair Encoding (BPE).
4. Creación de datasets y dataloaders personalizados.
5. Entrenamiento del modelo con PyTorch.
6. Generación automática de texto.

### Habilidades Demostradas
- Procesamiento de Lenguaje Natural (PLN)
- Preprocesamiento de datos
- Creación y manejo de datasets
- Fundamentos de Deep Learning
- Entrenamiento y evaluación de modelos
- Programación en Python
